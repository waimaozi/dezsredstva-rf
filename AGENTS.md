# Дезинфицирующиесредства.рф — Блог о дезинфекции

## Описание
Независимый информационный блог о дезинфицирующих средствах и дезинфекции. Переводные статьи мировых исследований, обзоры практик, полезные инструменты. Никаких продаж, никаких каталогов продуктов.

## Редакционный принцип (уточнение пользователя 16 октября 2026)

Читатели — специалисты по качеству и пищевой безопасности, ХАССП, сотрудники лабораторий и ОТК, технологи, ветеринарные специалисты и ответственные за санитарию и гигиену; прежде всего на пищевых производствах. Это роли из словаря специальной почты проекта базы контактов (`quality`, `otk`, `lab`, `haccp`, `foodsafety`, `technolog`, `vetvrach`, `sanitar`, `hygiene`), а не массовая бытовая аудитория.

Находим содержательные зарубежные материалы, полезные этим специалистам, и переводим их: исследования, эксперименты, расследования вспышек, технические разборы. Польза может выходить за узкую тему дезинфекции. Для каждого материала называем конкретного читателя и то, что он сможет узнать или применить в работе. Статус научной статьи сам по себе не доказывает пользу.

Wordstat и другие поисковые данные помогают обнаруживать интересы аудитории, но не задают обязательный заголовок или формат статьи. Не превращать сайт в очередной набор общих инструкций «как приготовить раствор». Не расширять аннотации в вымышленные статьи. Сохранять методы, результаты, ограничения, степень уверенности, рисунки и библиографию источника; точно указывать объём перевода. Делать русский текст и оригинал доступными для скачивания без доступа к зарубежному сайту. Редакционные пояснения отделять от перевода.

## Стек
- Astro + Tailwind CSS (SSG)
- Деплой: GitHub Pages
- Язык контента: русский

## Структура
- `/` — Главная: описание блога + лента последних статей
- `/articles/[slug]` — Статьи (Markdown/MDX в src/content/articles/)
- `/tools/` — Калькулятор разведения растворов

## Контент-модель
Статьи хранятся как .md файлы в src/content/articles/ с frontmatter:
```yaml
title: "Заголовок"
description: "Описание для SEO"
date: 2026-03-15
tags: ["исследования", "патогены"]
source: "https://pubmed.ncbi.nlm.nih.gov/..." # оригинал
```

## Дизайн
- Чистый, профессиональный, медицинская тематика
- Белый фон, синий/голубой акцент
- Мобильная адаптация
- Шрифт с поддержкой кириллицы

## SEO
- Meta title, description на каждой странице
- Sitemap.xml, robots.txt
- Schema.org (Article, Blog)
- Быстрая загрузка (статика)

## Спонсор
Единственное упоминание Химитек — строка в футере: "При поддержке chemitech.ru"
НЕТ каталогов, НЕТ продуктовых карточек, НЕТ упоминаний в контенте.
