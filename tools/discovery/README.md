# Проверка поисковой видимости

`measure.py` выполняет только чтение: Метрика (визиты, органические поисковые системы, входные страницы и цель `translation_download`), при наличии ключа — проверка `site:` через Yandex Search API. По умолчанию берёт семь завершённых суток по московскому времени. Расписания не создаёт.

```sh
python3 tools/discovery/measure.py \
  --oauth-file ~/.config/chemitech/ya_direct.token \
  --ssh russian-vps \
  --search-key-file /root/chemitech-enrichment-pilot-20261006/yandex-search.key \
  --out /tmp/dezsredstva-discovery.json
```

Для сравнения периодов задайте `--start YYYY-MM-DD --end YYYY-MM-DD`. `--webmaster` дополнительно проверяет доступ к Вебмастеру и сводку целевого сайта. OAuth передаётся в удалённый процесс через stdin; ключ Search API остаётся на сервере. Ответы не содержат токенов. Ошибки API сохраняются как неизвестный результат, а не как нулевые показатели.

## Как оценивать результат

1. В Вебмастере проверить дату обхода, страницы в поиске, причины исключения и нарушения. Подтверждённое число страниц в индексе брать оттуда, не из `site:`.
2. Сопоставить показы и клики по 12 переводам в отчёте поисковых запросов Вебмастера. Отсутствие доступа к этому отчёту означает пробел в данных.
3. В Метрике сравнить визиты из Яндекса и достижение цели скачивания. Разрез `landing_pages` относит цель к входной странице визита; это не число скачиваний конкретной статьи. Событие скачивания дополнительно передаёт `article`, `asset` и `format`.
4. Сравнивать полные периоды после подтверждённого повторного обхода. Принятие IndexNow не подтверждает индексирование; рост трафика после изменения сам по себе не доказывает его причину.

## Ежедневное наблюдение

С 17 октября 2026 года `dezsredstva-discovery.timer` на `russian-vps` запускает
`snapshot.py` ежедневно в 09:20 по Москве (плюс до двух минут разброса).
Первый реальный запуск завершился успешно. Каждая запись охватывает семь
завершённых суток, поэтому соседние записи перекрываются: складывать их нельзя.

Код установлен в `/opt/dezsredstva-discovery`, история и агрегированные данные
Метрики хранятся приватно в `/var/lib/dezsredstva-discovery`. `latest.json` —
последний полученный ответ, `health.json` — результат последней попытки,
`last-success.json` — дата последнего полного успешного чтения. Ошибки транспорта
не заменяют прежние данные нулями. При ошибке служба завершается с ненулевым
кодом и делает до трёх попыток за два часа; журнал доступен через
`journalctl -u dezsredstva-discovery.service`.

```sh
ssh russian-vps 'systemctl list-timers dezsredstva-discovery.timer --no-pager'
ssh russian-vps 'cat /var/lib/dezsredstva-discovery/health.json'
```

Ключ Search API остаётся на российском сервере. OAuth Метрики хранится отдельно
с правами 600 и поступает в процесс через stdin. Служба только читает данные;
она не отправляет письма, не меняет статьи и не считает ответ `site:` числом
страниц в индексе. Код 15 Search API означает отсутствие найденных документов;
другие коды ошибок делают результат неполным. Остановка: `systemctl disable
--now dezsredstva-discovery.timer`.
